# OpenSpec 继续变更

## 概述

恢复之前暂停的变更工作。

## 何时使用

- 变更工作被中断
- 需要恢复之前的工作
- 继续未完成的提案

## 流程

### 1. 查看变更状态

```bash
cat openspec/changes/<change-name>/proposal.md
```

### 2. 了解进度

- 哪些工作已完成？
- 哪些工作待完成？
- 有什么阻塞问题？

### 3. 继续实施

- 从上次停止的地方继续
- 更新进度记录
- 完成剩余工作
