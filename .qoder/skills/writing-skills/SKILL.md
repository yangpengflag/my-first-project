# 编写技能

## 概述

技能是 markdown 文件，教代理如何执行特定任务。

**核心原则：** 清晰、可操作、自包含。

## 技能结构

```markdown
---
name: skill-name
description: 何时使用此技能的描述
---

# 技能标题

## 概述

简要说明技能的目的和核心原则。

## 何时使用

明确列出适用和不适用的场景。

## 流程/步骤

具体的执行步骤，带检查清单。

## 示例

实际使用示例。

## 常见错误

| 错误 | 正确做法 |
|------|----------|
| ... | ... |

## 验证

如何验证技能已正确执行。
```

## 编写原则

### 1. 名称和描述

- 名称：kebab-case，动词开头
- 描述：何时使用，一句话

### 2. 概述

- 核心原则（1-2 句）
- 为什么重要

### 3. 何时使用

- 适用场景（具体）
- 不适用场景（明确）

### 4. 流程

- 编号步骤
- 每步可操作
- 带检查清单（如适用）

### 5. 示例

- 真实场景
- 展示输入/输出
- 好/坏对比

### 6. 常见错误

- 表格形式
- 错误 vs 正确做法

## 技能类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 流程技能 | 设定方法 | brainstorming, systematic-debugging |
| 实施技能 | 执行任务 | test-driven-development |
| 元技能 | 关于技能 | using-superpowers, writing-skills |

## 测试技能

创建技能后：
1. 在真实任务中试用
2. 收集反馈
3. 迭代改进
4. 更新文档

## 技能存放位置

- Qoder 项目：`.qoder/skills/<skill-name>/SKILL.md`
- Superpowers 项目：`skills/<skill-name>/SKILL.md`
