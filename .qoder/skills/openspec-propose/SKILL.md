# OpenSpec 创建提案

## 概述

为新的变更创建提案文档。

## 流程

1. 创建提案目录：
   ```bash
   mkdir -p openspec/changes/<change-name>
   ```

2. 编写提案：
   ```markdown
   # 变更提案

   ## 概述
   [简要描述]

   ## 动机
   [为什么需要这个变更]

   ## 范围
   [包含什么，不包含什么]

   ## 影响
   [影响哪些组件]
   ```

3. 编写增量规格

4. 获取批准
