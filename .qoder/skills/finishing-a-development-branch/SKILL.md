# 完成开发分支

## 概述

开发分支完成后的标准收尾流程。

**核心原则：** 确保所有工作已正确整合，无遗留问题。

## 流程

### 1. 验证完成标准

- [ ] 所有计划的任务已完成
- [ ] 所有测试通过
- [ ] 代码已审查（如适用）
- [ ] 规格已更新（如适用）

### 2. 清理工作

- [ ] 删除调试代码/注释
- [ ] 移除临时文件
- [ ] 更新文档（如需要）

### 3. 合并准备

- [ ] 与主分支同步
- [ ] 解决冲突
- [ ] 运行完整测试套件

### 4. 合并

- [ ] 创建合并请求（如适用）
- [ ] 获取批准
- [ ] 执行合并

### 5. 清理分支

- [ ] 删除远程分支
- [ ] 删除本地分支
- [ ] 更新跟踪分支

## 注意事项

- 不要跳过测试
- 不要强制推送（除非明确要求）
- 保留分支历史直到确认合并成功
