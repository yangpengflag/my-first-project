# OpenSpec 同步规格

## 概述

确保规格与代码实现保持一致。

## 何时使用

- 代码变更未更新规格
- 规格与实现不一致
- 定期维护

## 流程

### 1. 检查不一致

```bash
# 对比规格和代码
# 查找未记录的变更
```

### 2. 更新规格

- 添加缺失的规格
- 更新过时的规格
- 删除已废弃的规格

### 3. 验证

- [ ] 规格覆盖所有功能
- [ ] 规格与代码一致
- [ ] 无冲突

## 最佳实践

- 定期同步（每次发布前）
- 变更时立即更新规格
- 使用版本控制追踪规格变更
